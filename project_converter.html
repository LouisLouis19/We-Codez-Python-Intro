The Big Picture: Logic Separation

In the calculator, we only had 4 operations. Here, we can convert Celsius to Fahrenheit, Celsius to Kelvin, Fahrenheit to Celsius... there are 6 possible combinations!

Frontend vs Backend Roles
  • Frontend (converter.py): Asks user "What are we converting from?" and "What are we converting to?". Then it acts as a Traffic Controller to route the data.
  • Backend (backend_temperature.py): Contains the physics formulas. It doesn't know what the user selected, it just knows how to calculate.

Part 1: The Formulas (backend_temperature.py)

Specific Single-Purpose Functions

Lines 3-5:

def celsius_to_kelvin(val):
    kelvin = val + 273.15
    return kelvin

Each function does exactly one thing. This makes it easy to test. If Celsius to Kelvin conversion is wrong, we know exactly which 3 lines of code to check.

Part 2: The Traffic Controller (converter.py)

1. Reusable Input Helper

Lines 15-26:

def get_unit_choice(prompt_type):
    while True:
        print(f"\nSelect {prompt_type} Unit:")
        # ... prints 1. Celsius 2. Fahrenheit ...

We need to ask the user to choose a unit twice: once for the Source (Start) and once for the Target (End).
Instead of writing the same code twice, we create a function get_unit_choice. We pass in "Source" or "Target" as the prompt_type to slightly change what it prints.

2. The "Switchboard" Logic

Lines 34-53:

def convert(val, src, tgt):
    # Celsius Source
    if src == '1': 
        if tgt == '2': return backend_temperature.celsius_to_fahrenheit(val)
        if tgt == '3': return backend_temperature.celsius_to_kelvin(val)

This function determines which Backend function to call.
How it works:

  • If src == '1' (Celsius) AND tgt == '2' (Fahrenheit)...
  • ...then call the specific function celsius_to_fahrenheit(val).
This keeps the main part of our program clean. We just say "Convert this", and this function figures out how.

3. String Formating for Display

Line 69:

print(f"Result: ... {result:.2f} {get_unit_name(tgt_choice)}")

{result:.2f} tells Python to format the decimal number to only show 2 decimal places. So instead of 75.59999999, the user sees 75.60.
