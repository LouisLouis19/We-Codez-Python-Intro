🎯 What Are We Building?

We're building a Temperature Converter that can convert between Celsius, Fahrenheit, and Kelvin! The user selects what to convert FROM and what to convert TO.

🌡️ The Three Temperature Scales
Scale Water Freezes Water Boils Used In
Celsius (°C) 0°C 100°C Most countries, science
Fahrenheit (°F) 32°F 212°F USA, some Caribbean countries
Kelvin (K) 273.15K 373.15K Science (absolute scale)
🚦 The Traffic Controller Pattern

In the calculator, we had 4 operations. Here, we can convert between 6 different combinations:

  • Celsius → Fahrenheit
  • Celsius → Kelvin
  • Fahrenheit → Celsius
  • Fahrenheit → Kelvin
  • Kelvin → Celsius
  • Kelvin → Fahrenheit

The frontend acts as a Traffic Controller — it figures out which direction to go based on user input, then sends the request to the right backend function.

User Input
↓
Source: Kelvin (3) | Target: Celsius (1)
↓
Traffic Controller Logic
↓
backend_temperature.kelvin_to_celsius(val)
↓
Result Displayed

🔧 Part 1: The Formulas (backend_temperature.py)

This file contains the physics formulas for temperature conversion. Each function does exactly ONE thing — convert from one scale to another.

1. Celsius to Kelvin (Lines 3-5)

Lines 3-5:

def celsius_to_kelvin(val):
    kelvin = val + 273.15
    return kelvin
Understanding the formula:
  1. def celsius_to_kelvin(val): — Create a function that takes val (the temperature in Celsius).
  2. kelvin = val + 273.15 — The formula! Kelvin = Celsius + 273.15
    • 0°C = 273.15K (freezing point of water)
    • 100°C = 373.15K (boiling point of water)
  3. return kelvin — Give the answer back.
✅ Example
celsius_to_kelvin(25) # val = 25 # kelvin = 25 + 273.15 = 298.15 # return 298.15 # So: 25°C = 298.15K

2. Celsius to Fahrenheit (Lines 8-10)

Lines 8-10:

def celsius_to_fahrenheit(val):
    fahrenheit = (val * 9 / 5) + 32
    return fahrenheit
The formula: F = (C × 9/5) + 32

This is the classic conversion formula. Let's understand why it works:

  1. (val * 9 / 5) — Celsius and Fahrenheit have different "step sizes". For every 1°C change, Fahrenheit changes by 9/5 (or 1.8) degrees.
  2. + 32 — The freezing point of water is 0°C but 32°F. We add 32 to "shift" our scale.
✅ Example
celsius_to_fahrenheit(0) # val = 0 # fahrenheit = (0 * 9/5) + 32 = 0 + 32 = 32 # return 32 # So: 0°C = 32°F (freezing point!) ✓

3. Kelvin to Celsius (Lines 13-15)

Lines 13-15:

def kelvin_to_celcius(val):
    celcius = val - 273.15
    return celcius
The reverse of Celsius to Kelvin:

If Kelvin = Celsius + 273.15, then Celsius = Kelvin - 273.15. Simple!

4. Kelvin to Fahrenheit (Lines 18-20)

Lines 18-20:

def kelvin_to_fahrenheit(val):
    fahrenheit = (val - 273.15) * 1.8 + 32
    return fahrenheit
A two-step conversion:

This is actually doing TWO conversions in one formula:

  1. (val - 273.15) — First, convert Kelvin to Celsius
  2. * 1.8 + 32 — Then, convert Celsius to Fahrenheit

Note: 1.8 is the same as 9/5

5. Fahrenheit to Celsius (Lines 23-25)

Lines 23-25:

def fahrenheit_to_celsius(val):
    celsius = (val - 32) / 1.8
    return celsius
The reverse formula: C = (F - 32) / 1.8

This is the opposite of Celsius to Fahrenheit. We subtract 32 first, then divide.

6. Fahrenheit to Kelvin (Lines 28-30)

Lines 28-30:

def fahrenheit_to_kelvin(val):
    kelvin = (val - 32) * 5 / 9 + 273.15
    return kelvin
Another two-step conversion:
  1. (val - 32) * 5/9 — First, convert Fahrenheit to Celsius
  2. + 273.15 — Then, convert Celsius to Kelvin
🎯 Single-Purpose Functions

Notice how each function does exactly ONE thing? This is called the Single Responsibility Principle. Benefits:

  • Easy to test: If Celsius to Kelvin is wrong, we know exactly which 3 lines to fix.
  • Easy to read: The function name tells you exactly what it does.
  • Easy to reuse: If another program needs temperature conversion, just import this file!

🖥️ Part 2: The Traffic Controller (converter.py)

This file handles user interaction and determines which backend function to call based on the user's choices.

1. Importing Files (Lines 1-2)

Lines 1-2:

import backend_temperature
import sys
What we're importing:
  • backend_temperature — Our custom file with all the conversion formulas.
  • sys — Python's system module (optional, for advanced features).

2. Input Validation (Lines 4-10)

Lines 4-10:

def get_number(prompt):
    """Helper to get a valid number from user input."""
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("Invalid input. Please enter a numeric value.")
Same as the calculator!

This function keeps asking for a number until the user types a valid one. See the Calculator breakdown for a detailed explanation.

3. Reusable Unit Selection (Lines 15-26)

Lines 15-26:

def get_unit_choice(prompt_type):
    """Helper to get a valid unit choice."""
    while True:
        print(f"\nSelect {prompt_type} Unit:")
        print("1. Celsius")
        print("2. Fahrenheit")
        print("3. Kelvin")
        
        choice = input(f"Enter your choice (1/2/3): ").strip()
        if choice in ('1', '2', '3'):
            return choice
        print("Invalid choice. Please select 1, 2, or 3.")
Why create this function?

We need to ask the user to choose a unit twice: once for the SOURCE (what we're converting from) and once for the TARGET (what we're converting to).

Instead of writing the same code twice, we create a reusable function!

  1. def get_unit_choice(prompt_type): — Takes a string like "Source" or "Target"
  2. print(f"\nSelect {prompt_type} Unit:") — Uses an f-string to show "Select Source Unit:" or "Select Target Unit:"
  3. while True: — Keep asking until we get a valid answer (1, 2, or 3)
  4. if choice in ('1', '2', '3'): — Check if the input is valid
  5. return choice — Give back the user's choice
✅ Reusability in Action
# First call: get_unit_choice("Source") # Shows: "Select Source Unit:" # User picks 3 (Kelvin) # Returns: '3' # Second call: get_unit_choice("Target") # Shows: "Select Target Unit:" # User picks 1 (Celsius) # Returns: '1' # Same function, different output based on parameter!

4. Converting Numbers to Names (Lines 28-32)

Lines 28-32:

def get_unit_name(choice):
    if choice == '1': return "Celsius"
    if choice == '2': return "Fahrenheit"
    if choice == '3': return "Kelvin"
    return "Unknown"
Why do we need this?

The user selected '3' (a number). But when we display results, we want to show "Kelvin" (the name). This function converts numbers to names.

📝 Short-circuit Returns

Notice there's no elif or else between the if statements? That's because return immediately exits the function! Once we find a match, we return and the other lines never run.

5. The Traffic Controller Logic (Lines 34-53)

Lines 34-53:

def convert(val, src, tgt): # src = 3, tgt = 1
    if src == tgt:
        return val
    
    # Celsius Source
    if src == '1': 
        if tgt == '2': return backend_temperature.celsius_to_fahrenheit(val)
        if tgt == '3': return backend_temperature.celsius_to_kelvin(val)
    
    # Fahrenheit Source
    if src == '2':
        if tgt == '1': return backend_temperature.fahrenheit_to_celsius(val)
        if tgt == '3': return backend_temperature.fahrenheit_to_kelvin(val)

    # Kelvin Source
    if src == '3':
        if tgt == '1': return backend_temperature.kelvin_to_celsius(val)
        if tgt == '2': return backend_temperature.kelvin_to_fahrenheit(val)
    
    return val # Should not happen
This is the "switchboard" — it routes the conversion to the right function!
  1. def convert(val, src, tgt): — Takes three inputs:
    • val — the temperature value (e.g., 100)
    • src — source unit ('1', '2', or '3')
    • tgt — target unit ('1', '2', or '3')
  2. if src == tgt: return val — If source and target are the same (like Celsius to Celsius), just return the original value. No conversion needed!
  3. if src == '1': — If converting FROM Celsius...
    • if tgt == '2': — ...TO Fahrenheit → call celsius_to_fahrenheit
    • if tgt == '3': — ...TO Kelvin → call celsius_to_kelvin
  4. Same pattern repeats for Fahrenheit and Kelvin sources!
✅ Trace Through an Example
convert(300, '3', '1') # val = 300, src = '3' (Kelvin), tgt = '1' (Celsius) # Step 1: Is src == tgt? No (3 != 1), continue... # Step 2: Is src == '1'? No, skip... # Step 3: Is src == '2'? No, skip... # Step 4: Is src == '3'? YES! # Is tgt == '1'? YES! # Call: backend_temperature.kelvin_to_celsius(300) # Result: 300 - 273.15 = 26.85 # Return: 26.85 # So: 300K = 26.85°C ✓

6. The Main Function (Lines 55-75)

Lines 55-75:

def main():
    print("Welcome to the Temperature Converter!")
    print_separator()

    while True:
        print("\n--- New Conversion ---")
        src_choice = get_unit_choice("Source")
        tgt_choice = get_unit_choice("Target")
        
        val = get_number(f"Enter temperature in {get_unit_name(src_choice)}: ")
        
        result = convert(val, src_choice, tgt_choice)
        
        print_separator()
        print(f"Result: {val} {get_unit_name(src_choice)} = {result:.2f} {get_unit_name(tgt_choice)}")
        print_separator()
        
        cont = input("Do you want to perform another conversion? (y/n): ").strip().lower()
        if cont != 'y':
            print("\nThank you for using the converter. Goodbye!")
            break
The complete flow:
  1. print("Welcome...") — Greet the user.
  2. while True: — Start the main loop (keeps running until user quits).
  3. src_choice = get_unit_choice("Source") — Ask: "What are you converting FROM?"
  4. tgt_choice = get_unit_choice("Target") — Ask: "What are you converting TO?"
  5. val = get_number(f"...{get_unit_name(src_choice)}...") — Ask for the value. Notice how we use get_unit_name() to show "Enter temperature in Kelvin:" instead of "Enter temperature in 3:".
  6. result = convert(val, src_choice, tgt_choice) — Do the conversion!
  7. print(f"Result: ... {result:.2f} ...") — Display the result with 2 decimal places.
  8. cont = input("...").strip().lower() — Ask if they want to continue.
    • .strip() — Removes extra spaces
    • .lower() — Converts to lowercase (so "Y", "y", "YES" all work)
  9. if cont != 'y': break — If they didn't type "y", exit the loop.

7. Formatting Decimal Numbers

Key Line:

print(f"Result: {val} ... = {result:.2f} ...")
🔢 What is :.2f?

Inside an f-string, {result:.2f} means "format this number with 2 decimal places".

  • : — Start of format specifier
  • .2 — 2 decimal places
  • f — format as a float (decimal number)
result = 75.599999999 print(result) # Shows: 75.599999999 print(f"{result:.2f}") # Shows: 75.60 print(f"{result:.1f}") # Shows: 75.6 print(f"{result:.0f}") # Shows: 76
