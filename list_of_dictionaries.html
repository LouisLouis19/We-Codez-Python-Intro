Combining Lists and Dictionaries

By now, you've learned about Lists (ordered collections of items) and Dictionaries (key-value pairs describing a single object).

In the real world, data is rarely just a simple list of numbers or a single object. usually, we have a list of objects.

💡 The Spreadsheet Analogy

Think of a List of Dictionaries like a spreadsheet (Excel or Google Sheets):

  • The List is the whole sheet (the rows).
  • Each Dictionary is a single row (representing one person, one product, or one task).
  • The Keys are the column headers (Name, Age, Status).

The Structure

Let's look at how we structure data for a To-Do App.

1. A Single Task (Dictionary)

A single task has properties like what to do and whether it's done.

task1 = {
    "task": "Buy milk",
    "status": "pending"
}

2. A List of Tasks (List of Dictionaries)

Since we have many tasks, we put them inside a list.

todos = [
    { "task": "Buy milk", "status": "pending" },      # Index 0
    { "task": "Walk dog", "status": "completed" },    # Index 1
    { "task": "Do homework", "status": "pending" }    # Index 2
]

How to Access and Modify Data

To work with this structure, you combine the rules of lists (indexing) with the rules of dictionaries (keys).

1. Accessing a Specific Item

Syntax: list_name[index][key]

# Get the first task's name
print(todos[0]["task"])  
# Output: "Buy milk"

# Get the second task's status
print(todos[1]["status"]) 
# Output: "completed"

2. Modifying Data

You can change values just like you would with a normal variable.

# Mark the first task as completed
todos[0]["status"] = "completed"

# Change the name of the last task
todos[2]["task"] = "Finish Python Project"

3. Adding a New Item

Since it's a list, you use .append(). You append a new dictionary.

new_task = {
    "task": "Call Mom",
    "status": "pending"
}

todos.append(new_task)

Looping Through the Data

This is the most common pattern you will see in apps. We loop through the list, and for each item (dictionary), we access its keys.

for todo in todos:
    # 'todo' is the dictionary for the current iteration
    print(f"Task: {todo['task']} - Status: {todo['status']}")

# Output:
# Task: Buy milk - Status: completed
# Task: Walk dog - Status: completed
# Task: Finish Python Project - Status: pending
# Task: Call Mom - Status: pending

Practice Exercises

Exercise 1: Student Grades

Create a list of dictionaries representing students. Each student should have a "name" and a "grade".

Show Solution 
students = [
    {"name": "Alice", "grade": 85},
    {"name": "Bob", "grade": 92},
    {"name": "Charlie", "grade": 78}
]

# Print Bob's grade
print(students[1]["grade"])

Exercise 2: Finding a Value

Loop through the students list above and print the name of any student with a grade higher than 90.

Show Solution 
for student in students:
    if student["grade"] > 90:
        print(student["name"])
# Output: Bob
