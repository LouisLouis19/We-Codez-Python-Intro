What is Bubble Sort?

Bubble Sort is one of the simplest sorting algorithms. It works by repeatedly comparing adjacent elements (elements that are next to each other) and swapping them if they are in the wrong order.

After each full pass through the list, the largest remaining unsorted element "bubbles up" to its correct position at the end — just like how air bubbles rise to the top of water.

Real-Life Analogy: Sorting Cards

Imagine you're holding a hand of playing cards: 5, 2, 8, 1, 9.

You compare every pair of adjacent cards from left to right. If the left card is bigger than the right card, you swap them. After one full pass, the biggest card (9) is guaranteed to be at the far right. You then repeat the process for the remaining unsorted cards.

The "Sorted Zone" Grows from the Right

After each pass, one more element is permanently placed at the right end in its correct sorted position. The sorted zone grows from right to left, and the unsorted zone shrinks from left to right. 

numbers = [5, 2, 8, 1, 9]

# After Pass 1:  [2, 5, 1, 8, | 9]    → 9 is in its final place ✓
# After Pass 2:  [2, 1, 5, | 8, 9]    → 8 is in its final place ✓
# After Pass 3:  [1, 2, | 5, 8, 9]    → 5 is in its final place ✓
# After Pass 4:  [1, | 2, 5, 8, 9]    → 2 is in its final place ✓
# Done! [1, 2, 5, 8, 9]

Detailed Trace — One Full Pass

Let's trace through the very first pass on [5, 2, 8, 1, 9]: 

Starting list: [5, 2, 8, 1, 9]

Compare index 0 and 1: [5, 2] → 5 > 2? YES → SWAP
List: [2, 5, 8, 1, 9]

Compare index 1 and 2: [5, 8] → 5 > 8? NO  → No swap
List: [2, 5, 8, 1, 9]

Compare index 2 and 3: [8, 1] → 8 > 1? YES → SWAP
List: [2, 5, 1, 8, 9]

Compare index 3 and 4: [8, 9] → 8 > 9? NO  → No swap
List: [2, 5, 1, 8, 9]

End of Pass 1: The largest element (9) is now at the end! ✓

Notice how 9 never got swapped — it was already in the right place and just "passed through" comparisons. The key observation is that after each pass, the largest unsorted element bubbles to the end.

Bubble Sort in Python

def bubble_sort(arr):
    n = len(arr)

    # Outer loop: controls how many passes we do
    # After each pass, the last 'i' elements are already sorted
    for i in range(n):

        # Inner loop: compare adjacent elements
        # We go up to n-1-i because the last i elements are already sorted
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:     # If left > right, they're in wrong order
                # Swap them!
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

    return arr


# --- Test it! ---
numbers = [5, 2, 8, 1, 9]
print(bubble_sort(numbers))   # Output: [1, 2, 5, 8, 9]

more_numbers = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(more_numbers))   # Output: [11, 12, 22, 25, 34, 64, 90]

Understanding the Two Loops

  • Outer loop (for i in range(n)): Controls how many passes we make. Runs n times. After each pass, one more element is permanently placed.
  • Inner loop (for j in range(n - 1 - i)): Compares adjacent pairs within the unsorted portion. We use n - 1 - i because we don't need to compare the already-sorted elements at the end (i elements are sorted).

All Passes Traced on [5, 2, 8, 1, 9]

Initial:  [5, 2, 8, 1, 9]

Pass 1 (i=0): Compare pairs from index 0 to 3
  [5,2,8,1,9] → 5>2? YES → [2,5,8,1,9]
  [2,5,8,1,9] → 5>8? NO  → [2,5,8,1,9]
  [2,5,8,1,9] → 8>1? YES → [2,5,1,8,9]
  [2,5,1,8,9] → 8>9? NO  → [2,5,1,8,9]
After Pass 1: [2, 5, 1, 8, | 9]   → 9 is sorted ✓

Pass 2 (i=1): Compare pairs from index 0 to 2
  [2,5,1,8,9] → 2>5? NO  → [2,5,1,8,9]
  [2,5,1,8,9] → 5>1? YES → [2,1,5,8,9]
  [2,1,5,8,9] → 5>8? NO  → [2,1,5,8,9]
After Pass 2: [2, 1, 5, | 8, 9]   → 8 is sorted ✓

Pass 3 (i=2): Compare pairs from index 0 to 1
  [2,1,5,8,9] → 2>1? YES → [1,2,5,8,9]
  [1,2,5,8,9] → 2>5? NO  → [1,2,5,8,9]
After Pass 3: [1, 2, | 5, 8, 9]   → 5 is sorted ✓

Pass 4 (i=3): Compare pairs from index 0 to 0
  [1,2,5,8,9] → 1>2? NO  → [1,2,5,8,9]
After Pass 4: [1, | 2, 5, 8, 9]   → 2 is sorted ✓

Final: [1, 2, 5, 8, 9] ✓

Bubble Sort on Strings

Bubble Sort works on strings too! Python compares strings alphabetically using < and >. For example, "Apple" < "Banana" because "A" comes before "B" in the alphabet. 

def bubble_sort_strings(arr):
    n = len(arr)

    for i in range(n):
        for j in range(n - 1 - i):
            # String comparison: alphabetical order
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

    return arr

fruits = ["Banana", "Apple", "Cherry", "Date", "Elderberry"]
print(bubble_sort_strings(fruits))
# Output: ['Apple', 'Banana', 'Cherry', 'Date', 'Elderberry']
# Tracing the first pass:
# ["Banana", "Apple", "Cherry"] → "Banana" > "Apple"? YES → swap
# → ["Apple", "Banana", "Cherry"]
# "Banana" > "Cherry"? NO → no swap
# ...and so on.
# Python compares strings character by character, just like a dictionary!

Optimization: Early Stopping

If the list is already sorted (or becomes sorted early), bubble sort will still run all passes — wasting time. We can add an optimization: if no swaps happen during a pass, the list is already sorted, and we can stop early! 

def bubble_sort_optimized(arr):
    n = len(arr)

    for i in range(n):
        swapped = False   # Track if any swap was made this pass

        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True    # We made a swap!

        if not swapped:
            break   # No swaps → list is fully sorted → stop early!

    return arr

# Already sorted list — stops immediately after Pass 1!
print(bubble_sort_optimized([1, 2, 3, 4, 5]))   # Output: [1, 2, 3, 4, 5]

2. What is "Bubbling"?

Explain in your own words: what exactly is "bubbling" in Bubble Sort? What value bubbles to where, and after which pass?

Solution 
# In each pass, the LARGEST unsorted value "bubbles" to the end of the unsorted portion.
# This is because whenever a large number is compared with its right neighbor and found
# to be bigger, it gets swapped — and keeps getting swapped all the way to the right.
#
# After Pass 1: the LARGEST value is at the end (index n-1).
# After Pass 2: the 2nd LARGEST value is at position n-2.
# After Pass k: the k largest values are in their final positions at the right.

4. Already Sorted

What happens if you run bubble_sort_optimized on a list that is already sorted, like [1, 2, 3, 4, 5]? How many passes does it make?

Solution 
# Pass 1: Compare all adjacent pairs → no swaps needed → swapped = False → STOP!
# Total: only 1 pass needed!
# Without the optimization, it would still run 5 passes even though the list is sorted.

print(bubble_sort_optimized([1, 2, 3, 4, 5]))   # Output: [1, 2, 3, 4, 5]
# Runs only 1 pass.

5. How Many Passes?

For a list of n items, how many passes does Bubble Sort make in the worst case? Why is it called O(n²)?

Solution 
# Worst case: the list is sorted in REVERSE order (e.g., [9, 8, 7, 6, 5]).
# 
# We need n-1 passes (n items → at most n-1 elements need to be moved to the end).
# In each pass, we do up to n-1 comparisons.
#
# Total comparisons ≈ (n-1) + (n-2) + ... + 1 = n(n-1)/2 ≈ O(n²)
#
# Example: n=5 → at most 4+3+2+1=10 comparisons.

Time Complexity

Bubble Sort uses two nested loops — the outer loop runs n times, and the inner loop runs up to n times per pass. This gives us a quadratic time complexity.

Case Time Complexity When does it happen?
Best Case O(n) The list is already sorted — with early stopping, we detect this in just 1 pass.
Average Case O(n²) Elements are in a random order — about half the comparisons lead to swaps.
Worst Case O(n²) The list is sorted in reverse order — every comparison requires a swap.

What does O(n²) mean in practice?

# n = number of items in the list

n = 10        →  up to  45 comparisons
n = 100       →  up to  4,950 comparisons
n = 1,000     →  up to  499,500 comparisons
n = 10,000    →  up to  ~50,000,000 comparisons  ← Very slow for large lists!

# In the worst case (reversed list), the inner loop total comparisons =
# (n-1) + (n-2) + ... + 1 = n(n-1)/2  →  O(n²)

# For comparison, Python's built-in sort (Timsort) does this in O(n log n) —
# much faster for large lists! Bubble Sort is mainly used for learning.

Space Complexity

Bubble Sort works in-place — it only swaps elements within the original list and doesn't create any extra lists. It only needs a couple of temporary variables for the swap. That's O(1) extra space — very memory efficient.
