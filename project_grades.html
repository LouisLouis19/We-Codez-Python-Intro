🎯 What Are We Building?

We're building a Student Grade Manager — a simple app to track students and their grades! You can add students, add grades for each student, and view all students with their grade averages.

🌟 Perfect for Beginners!

This is a revision project — it's designed to help you practice everything you've learned! It's simpler than some other projects, but it reinforces the most important concepts.

📚 What Does a Grade Manager Do?

Think of a teacher's gradebook:

  • Add students to the class
  • Record grades for each student (tests, homework, etc.)
  • Calculate averages to see how each student is doing
🔑 Key Concepts Practiced
  • Lists of Dictionaries: Each student is a dictionary in a list
  • Lists Inside Dictionaries: Each student has a list of grades
  • Passing Lists to Functions: Data passed as parameters
  • Calculating Averages: Sum divided by count
  • Error Handling: What if a list is empty?

🔧 Part 1: The Backend (backend_grades.py)

Let's break down each function in the backend.

1. Adding a Student (Lines 33-36)

Lines 33-36:

def add_student(students, name):
    new_student = {"name": name, "grades": []}
    students.append(new_student)
    return students
Step by step:
  1. new_student = {"name": name, "grades": []} — Create a dictionary with the student's name and an empty grades list.
  2. students.append(new_student) — Add this dictionary to the list.
  3. return students — Return the updated list.
✅ Trace Example
# Before: students = [] add_student(students, "Kayleen") # After: students = [{"name": "Kayleen", "grades": []}] add_student(students, "Stephanie") # After: students = [ # {"name": "Kayleen", "grades": []}, # {"name": "Stephanie", "grades": []} # ]

2. Adding a Grade (Lines 19-29)

Lines 19-29:

def add_grade(students, name, grade):
    for student in students:
        # 1st Run: student = {"name": "Kayleen", "grades": [0, 100]}
        # 2nd Run: student = {"name": "Stephanie", "grades": [100]}
        if student["name"] == name:
            # student["grade"] = grade  # Update score (1st Assumption)
            student["grades"].append(grade)
            return students
    new_student = {"name": name, "grades": [grade]}
    students.append(new_student)
    return students
Two scenarios:
  1. Student EXISTS: Find them, append the grade to their list.
  2. Student DOESN'T EXIST: Create a new student with this grade!
🎨 The Code Comments Are Learning Tools!

Notice the comments like # 1st Run: student = ...? These show you what the variable contains during each loop iteration. This is a great way to learn and debug!

⚠️ Auto-Creating Students

This function is "smart" — if you try to add a grade for a student that doesn't exist, it creates the student automatically!

students = [] # Empty add_grade(students, "Kayleen", 100) # Kayleen doesn't exist → creates her with grade 100 # Result: [{"name": "Kayleen", "grades": [100]}]
✅ Adding Multiple Grades
# Start: [{"name": "Kayleen", "grades": [100]}] add_grade(students, "Kayleen", 90) # Kayleen exists → append 90 # Result: [{"name": "Kayleen", "grades": [100, 90]}] add_grade(students, "Kayleen", 85) # Kayleen exists → append 85 # Result: [{"name": "Kayleen", "grades": [100, 90, 85]}]

3. Getting All Students (Lines 40-41)

Lines 40-41:

def get_all_students(students):
    return students
🤔 Why Have This Function?

This function just returns the list — so why have it? A few reasons:

  • Consistency: All data access goes through functions
  • Future-proofing: Later you could add filtering or sorting
  • Abstraction: The frontend doesn't need to know how data is stored

4. Calculating the Average (Lines 44-47)

Lines 44-47:

def calculate_average(student_grade):
    if len(student_grade) == 0:
        return 0
    return sum(student_grade) / len(student_grade)
Understanding the math:
  1. if len(student_grade) == 0: — Check if the list is empty.
  2. return 0 — If empty, return 0 (can't divide by zero!).
  3. sum(student_grade) — Add all grades together.
  4. len(student_grade) — Count how many grades.
  5. sum / len — Divide to get the average.
⚠️ Division by Zero!

If a student has no grades, len(student_grade) is 0, and dividing by 0 would crash the program! That's why we check first.

grades = [] sum(grades) # Returns 0 len(grades) # Returns 0 0 / 0 # ERROR! Cannot divide by zero! # That's why we check: if len(grades) == 0: return 0
✅ Average Calculation Example
grades = [100, 90, 80, 70] sum(grades) # 100 + 90 + 80 + 70 = 340 len(grades) # 4 340 / 4 = 85.0 # Average!

2. Adding a Student (Lines 22-25)

3. Adding a Grade (Lines 27-36)

Lines 27-36:

elif choice == '2':
    name = input("Enter student name: ")
    try:
        grade = float(input("Enter grade: "))
        if backend_grades.add_grade(students, name, grade):
            print(f"Grade {grade} added for {name}.")
        else:
            print(f"Student '{name}' not found.")
    except ValueError:
        print("Invalid grade. Please enter a number.")
With error handling:
  1. Ask for the student name.
  2. Ask for the grade (could be a decimal like 87.5).
  3. Convert with float() — might fail if user types "abc".
  4. If conversion fails, catch the error and show a message.

4. Viewing Students with Averages (Lines 38-46)

Lines 38-46:

elif choice == '3':
    all_students = backend_grades.get_all_students(students)
    if not all_students:
        print("No students found.")
    else:
        for student in all_students:
            # Calculate average using backend function
            avg = backend_grades.calculate_average(student["grades"])
            print(f"Name: {student['name']}, Grades: {student['grades']}, Average: {avg:.2f}")
Breaking it down:
  1. all_students = get_all_students(students) — Get the full list.
  2. if not all_students: — Check if empty.
  3. for student in all_students: — Loop through each student.
  4. student["grades"] — Get their grades list.
  5. calculate_average(student["grades"]) — Calculate their average.
  6. {avg:.2f} — Format average to 2 decimal places.
✅ Output Example
Name: Kayleen, Grades: [100, 90, 80, 70], Average: 85.00 Name: Stephanie, Grades: [100], Average: 100.00 Name: Louis, Grades: [50], Average: 50.00

🚀 How the Program Starts

The Entry Point (Lines 55-56)

Lines 55-56:

if __name__ == "__main__":
    main()
📘 What Does This Mean?

__name__ is a special Python variable:

  • When you RUN a file directly (e.g., python3 grade_app.py), __name__ equals "__main__"
  • When a file is IMPORTED, __name__ equals the file's name

So this code says: "Only run main() if this file is being run directly, not imported."

💡 The Comments at the Top!

The file includes helpful comments: 

# 1. Code starts from main()
# 2. Run Code --> From File with main() // python3 grade_app.py (File name)

This tells you: "The program starts at main(), and you run it with python3 grade_app.py."
