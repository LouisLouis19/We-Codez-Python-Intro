What is an Algorithm?

An algorithm is a step-by-step set of instructions for solving a problem. Think of it like a recipe — you follow the steps in order and you get the result at the end.

In programming, algorithms help us solve problems efficiently. Two programs might produce the same answer, but one could be 1,000 times faster — that's the power of choosing the right algorithm!

In this section, we will explore six fundamental algorithms and techniques that every programmer should know. Each algorithm has its own dedicated page with a full explanation, worked examples, and practice questions.

Algorithms Covered

1. Binary Search

What it is: A fast searching technique that works on a sorted list by repeatedly cutting the search space in half.

When to use it: When you need to search a sorted list quickly.

→ Go to Binary Search

2. Two Sum (Hash Map)

What it is: A technique to find two numbers in a list that add up to a target, using a dictionary (hash map) to remember what we've already seen.

When to use it: When you need to find a pair (or complement) in a list.

→ Go to Two Sum

3. Two Pointers

What it is: A technique where you use two index variables (pointers) to scan a list — often from both ends toward the middle, or both moving in the same direction.

When to use it: Sorted arrays, checking palindromes, removing duplicates, finding pairs.

→ Go to Two Pointers

4. Sliding Window

What it is: A technique to efficiently process a subarray (a group of consecutive elements) by "sliding" a fixed or variable-size window across the list.

When to use it: When you need the maximum/minimum sum of a subarray of size k.

→ Go to Sliding Window

5. Bubble Sort

What it is: A simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order. Larger values "bubble" to the end.

When to use it: Great for learning sorting — simple to understand and implement.

→ Go to Bubble Sort

6. Insertion Sort

What it is: A sorting algorithm that builds the sorted list one element at a time, inserting each new element into its correct position in the already-sorted portion.

When to use it: Efficient for small or nearly-sorted lists.

→ Go to Insertion Sort

Quick Comparison

Algorithm Type Works On Key Idea
Binary Search Searching Sorted list Halve the search space each step
Two Sum Pair Finding Any list Use a dictionary to remember seen values
Two Pointers Traversal Arrays / Strings Use two index variables to avoid nested loops
Sliding Window Subarray Arrays Slide a fixed window to track a portion
Bubble Sort Sorting Any list Swap adjacent pairs until sorted
Insertion Sort Sorting Any list Insert each element into correct position
