🎯 What Are We Building?

We're building an Expense Tracker — a personal finance app that tracks your income and expenses! You can add money you earn (income), money you spend (expenses), and see how much money you have left.

💰 Personal Finance 101

Managing money is simple math:

Remaining Balance = Total Income - Total Expenses Example: You earned: $5,000 (salary) You spent: $1,350.50 (rent + groceries) You have: $3,649.50 left!
🆕 What's New in This Project?
  • Two Types of Data: Income AND Expenses (tracked with a "type" field)
  • Unique IDs: Each transaction has a unique ID number
  • Calculated Summaries: The app calculates totals and balances
  • Formatted Tables: Data displayed in neat columns
  • Date Tracking: Each transaction records when it happened

📊 Understanding the Data

📦 What Information Does Each Transaction Need?

Every transaction (income or expense) needs these pieces of information:

Field Type Example Why We Need It
id Integer 1, 2, 3... Unique identifier to find/delete specific transactions
name String "Salary", "Groceries" Description of what the money is for
amount Float 5000.0, 150.50 How much money (always positive)
category String "Salary", "Food", "Housing" Group similar transactions together
type String "income" or "expense" Is this money coming IN or going OUT?
date String "2024-01-15" When did this transaction happen?

The Data Structure

transactions = [ { "id": 1, "name": "Salary", "amount": 5000.0, "category": "Salary", "type": "income", # Money coming IN "date": "2024-01-01" }, { "id": 2, "name": "Groceries", "amount": 150.50, "category": "Food", "type": "expense", # Money going OUT "date": "2024-01-02" }, { "id": 3, "name": "Rent", "amount": 1200.0, "category": "Housing", "type": "expense", # Money going OUT "date": "2024-01-03" } ]
⚠️ The "type" Field is Critical!

The "type" field tells us whether to add or subtract this amount from our balance:

  • "income" → Add to balance (money we receive)
  • "expense" → Subtract from balance (money we spend)

🔧 Part 1: The Data Manager (backend_expense.py)

This file stores all transactions and provides functions to add, delete, and calculate totals.

1. Setting Up Storage (Lines 1-6)

Lines 1-6:

import datetime

# Data storage
transactions = []
current_id = 1
Understanding each line:
  1. import datetime — Import Python's datetime library to work with dates.
  2. transactions = [] — Create an empty list to store all our transaction dictionaries.
  3. current_id = 1 — A counter to give each transaction a unique ID.
    • First transaction gets ID 1
    • Second transaction gets ID 2
    • And so on...
🔢 Why Use Unique IDs?

Unlike the To-Do app where we used the index (position) to identify items, this app uses unique IDs. Why?

  • Indexes change: If you delete item at index 1, everything shifts!
  • IDs stay constant: Transaction #5 is ALWAYS transaction #5, even if others are deleted.
# With indexes (To-Do app style): Before delete: [Item0, Item1, Item2] # Delete Item1 After delete: [Item0, Item2] # Item2 is now at index 1! # With IDs (Expense Tracker style): Before delete: [ID:1, ID:2, ID:3] # Delete ID:2 After delete: [ID:1, ID:3] # ID:3 is still ID:3!

Let's see how these would work:

3. Adding a Transaction (Concept)

Here's how an add_transaction function would work:

def add_transaction(name, amount, category, trans_type):
    """Adds a new transaction (income or expense)."""
    global transactions, current_id
    
    if amount <= 0:  # Amount must be positive!
        return False
    
    new_transaction = {
        "id": current_id,
        "name": name,
        "amount": amount,
        "category": category,
        "type": trans_type,  # "income" or "expense"
        "date": datetime.date.today().isoformat()  # Today's date
    }
    
    transactions.append(new_transaction)
    current_id += 1  # Increment for next transaction
    return True
Key points:
  1. if amount <= 0: return False — Validate that amounts are positive.
  2. "id": current_id — Use the current ID counter.
  3. datetime.date.today().isoformat() — Get today's date in "YYYY-MM-DD" format.
  4. current_id += 1 — Increment so the next transaction gets a new ID.

4. Calculating the Balance (Concept)

Here's how a get_balance_summary function would work:

def get_balance_summary():
    """Calculates and returns financial summary."""
    total_income = 0
    total_expenses = 0
    
    for t in transactions:
        if t["type"] == "income":
            total_income += t["amount"]
        else:  # type == "expense"
            total_expenses += t["amount"]
    
    return {
        "original_balance": total_income,
        "total_expenses": total_expenses,
        "remaining_balance": total_income - total_expenses
    }
The logic:
  1. Loop through ALL transactions.
  2. Check the "type" field of each transaction.
  3. If "income" → add to total_income.
  4. If "expense" → add to total_expenses.
  5. Return a dictionary with all three values.
📦 Returning a Dictionary

This function returns a dictionary with multiple values, not just one number!

summary = get_balance_summary() # summary is now: # { # "original_balance": 5000.0, # "total_expenses": 1350.50, # "remaining_balance": 3649.50 # } # Access each value: print(summary["original_balance"]) # 5000.0 print(summary["total_expenses"]) # 1350.50 print(summary["remaining_balance"]) # 3649.50

elif choice == '4':

    if not transactions:

    else:

        print("-" * 75)
        for t in transactions:
            print(f"{t['id']:<5} {t['name']:<20} ${t['amount']:<9.2f} {t['type']:<10} {t['category']:<15} {t['date']:<12}")
📏 String Formatting with Width

The <5, <20, etc. are width specifiers. They make columns line up neatly!

  • {'ID':<5} — "ID" padded to 5 characters, left-aligned
  • {'Name':<20} — "Name" padded to 20 characters, left-aligned
  • {t['amount']:<9.2f} — Amount with 2 decimals, padded to 9 characters
# Without width specifiers: 1 Salary 5000.0 income Salary 2024-01-01 2 Groceries 150.5 expense Food 2024-01-02 # With width specifiers: ID Name Amount Type Category Date ------------------------------------------------------------- 1 Salary $5000.00 income Salary 2024-01-01 2 Groceries $150.50 expense Food 2024-01-02

Much easier to read!
