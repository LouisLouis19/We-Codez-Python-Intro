Introduction to Debugging

Debugging is a crucial skill in programming, helping you find and fix errors in your code. One of the simplest and most effective debugging techniques is using print statements to inspect values and the flow of execution.

Using Print Statements for Debugging

1. Debugging Functions

Place print statements inside functions to track parameter values and intermediate calculations.

def multiply(a, b):
    print(f"Inside multiply: a={a}, b={b}")
    result = a * b
    print("Result of multiplication:", result)
    return result

x = 3
y = 4
product = multiply(x, y)
print("Final result:", product)
          
def divide(a, b):
    print(f"Dividing {a} by {b}")
    if b == 0:
        print("Error: Cannot divide by zero!")
        return None
    result = a / b
    print("Division result:", result)
    return result

divide(10, 2)
divide(5, 0)
          
def reverse_string(s):
    print(f"Original string: {s}")
    reversed_s = s[::-1]
    print("Reversed string:", reversed_s)
    return reversed_s

reverse_string("hello")

2. Debugging Code Execution Inside a Function

Use print statements to track function execution step by step.

def find_max(a, b, c):
    print(f"Checking values: a={a}, b={b}, c={c}")
    if a > b and a > c:
        print("a is the largest")
        return a
    elif b > c:
        print("b is the largest")
        return b
    else:
        print("c is the largest")
        return c

print(find_max(7, 3, 9))
          
def sum_list(numbers):
    print("List contents:", numbers)
    total = 0
    for num in numbers:
        print(f"Adding {num} to total")
        total += num
    print("Final sum:", total)
    return total

sum_list([3, 1, 4, 1, 5, 9])

3. Debugging Loops

Print values inside loops to track iteration behavior.

for i in range(1, 6):
    print(f"Loop iteration {i}")
          
numbers = [2, 4, 6, 8]
for i, num in enumerate(numbers):
    print(f"Index {i}: {num}")
          
x = 10
while x > 0:
    print("Current value of x:", x)
    x -= 2

4. Debugging Data Structure Contents

Print the contents of lists, sets, and dictionaries to verify expected values.

# Debugging lists
fruits = ["apple", "banana", "cherry"]
print("Fruits list:", fruits)
          
# Debugging sets
unique_nums = {1, 2, 3, 4, 5}
print("Set contents:", unique_nums)
          
# Debugging dictionaries
student = {"name": "John", "grade": "A"}
print("Student details:", student)
          
# More complex dictionary debugging
team = {
    "players": ["Alice", "Bob", "Charlie"],
    "coach": "David",
    "wins": 5
}
print("Team details:", team)
print("Coach name:", team["coach"])
