🎯 What Are We Building?

We're building an Inventory Management System — software that a store or warehouse would use to track products! You can view products, add new ones, update stock quantities, search for items, and calculate the total value of inventory.

📦 What is Inventory Management?

Imagine you run a store. You need to know:

  • What products do you have? (Laptops, chairs, notebooks...)
  • How many of each? (10 laptops, 25 chairs...)
  • What's each worth? ($999.99 per laptop...)
  • Who supplies them? (TechCorp, SitWell...)
🆕 What's New in This Project?
  • Passing Data as Parameters: The inventory list is passed TO functions, not stored globally
  • Dynamic ID Generation: max() function finds the highest ID
  • Case-Insensitive Search: Using .lower() for flexible searching
  • Substring Matching: Search finds partial matches
  • Calculations: Total value = price × quantity for each item

2. Adding New Products (Lines 56-74)

Lines 56-74:

def add_item(inventory, name, category, price, quantity, supplier):
    """Adds a new item to the inventory."""
    # Simple ID generation: max ID + 1 or 1 if empty
    new_id = 1
    if inventory:
        new_id = max(item["id"] for item in inventory) + 1
        
    new_item = {
        "id": new_id,
        "product_name": name,
        "category": category,
        "price": float(price),
        "stock_quantity": int(quantity),
        "supplier": supplier
    }
    inventory.append(new_item)
    return new_item
Understanding the ID generation:
  1. if inventory: — Check if the list is not empty.
  2. max(item["id"] for item in inventory) — Find the HIGHEST ID in the list.
    • This is a generator expression — it loops through all items and extracts the "id" field.
    • max() finds the largest value.
  3. + 1 — Add 1 to get the next available ID.
✅ ID Generation Example
# Current inventory has IDs: [1, 2, 3, 4, 5] max(item["id"] for item in inventory) # Returns 5 new_id = 5 + 1 # new_id = 6 # Even if we delete ID 3: # Inventory has IDs: [1, 2, 4, 5] max(...) # Still returns 5 new_id = 6 # IDs are never reused!
📝 Generator Expression vs For Loop

max(item["id"] for item in inventory) is a compact way to write:

# Generator expression (one line): max_id = max(item["id"] for item in inventory) # Equivalent for loop (multiple lines): all_ids = [] for item in inventory: all_ids.append(item["id"]) max_id = max(all_ids)

Same result, but the generator expression is more elegant!

3. Updating Stock Quantity (Lines 76-86)

Lines 76-86:

def update_stock(inventory, product_name, new_quantity):
    """
    Updates the stock quantity of a product by name.
    Returns True if found, False otherwise.
    """
    for item in inventory:
        # Case-insensitive comparison
        if item["product_name"].lower() == product_name.lower():
            item["stock_quantity"] = int(new_quantity)
            return True
    return False
Understanding case-insensitive comparison:
  1. for item in inventory: — Loop through all products.
  2. item["product_name"].lower() — Convert product name to lowercase.
  3. product_name.lower() — Convert user's input to lowercase.
  4. Compare the lowercase versions!
✅ Case-Insensitive Matching
# Product in inventory: "Laptop" # User types: "laptop" or "LAPTOP" or "LaPtOp" "Laptop".lower() # "laptop" "laptop".lower() # "laptop" "LAPTOP".lower() # "laptop" "LaPtOp".lower() # "laptop" # All match! 👍

4. Searching Products (Lines 88-97)

Lines 88-97:

def search_item(inventory, name):
    """
    Searches for an item by name (case-insensitive substring).
    Returns a list of matching items.
    """
    results = []
    for item in inventory:
        if name.lower() in item["product_name"].lower():
            results.append(item)
    return results
Understanding substring search:
  1. results = [] — Create empty list for matches.
  2. name.lower() in item["product_name"].lower() — Check if the search term appears ANYWHERE in the product name.
  3. If it does, add the whole item to results.
  4. Return all matches (could be 0, 1, or many).
🔍 Substring vs Exact Match
# Exact match (==): "Laptop" == "lap" # False "Laptop" == "Laptop" # True # Substring match (in): "lap" in "Laptop" # True! "lap" is inside "Laptop" "top" in "Laptop" # True! "top" is inside "Laptop" "xyz" in "Laptop" # False, "xyz" is not inside # Practical example: search_item(inventory, "wire") # Would find: "Wireless Mouse", "Wireless Keyboard", etc.

5. Calculating Total Inventory Value (Lines 99-106)

Lines 99-106:

def calculate_total_value(inventory):
    """
    Calculates the total value of all items in stock (price * quantity).
    """
    total = 0
    for item in inventory:
        total += item["price"] * item["stock_quantity"]
    return total
The math:

Total Value = Sum of (price × quantity) for each product

✅ Calculation Example
Laptop: $999.99 × 10 = $9,999.90 Office Chair: $149.50 × 25 = $3,737.50 Coffee Maker: $45.00 × 15 = $675.00 Wireless Mouse: $19.99 × 50 = $999.50 Notebook: $2.50 × 100 = $250.00 ───────────── Total Inventory Value: $15,661.90

💲 Number Formatting with Commas

{total:,.2f} formats the number with:

  • , — Thousands separator (commas)
  • .2f — Two decimal places
