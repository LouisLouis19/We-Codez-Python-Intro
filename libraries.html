Overview

Imagine you are building a house. You don't make every hammer, saw, and drill yourself; you buy a toolbox that already has them!

In Python, Libraries (or Modules) are like those toolboxes. They are collections of code that others have written to solve common problems, so you don't have to reinvent the wheel.

What is a Module?

A module is simply a file containing Python code (functions, variables, classes). Python comes with a huge collection of modules built-in, known as the Standard Library.

To use these tools, you need to import them into your code.

How to Import Modules

There are a few ways to bring a module's code into your program.

1. Import the entire module

Use the import keyword followed by the module name.

import math

print(math.sqrt(16))  # Output: 4.0

Note that you have to use math. before using any function from the module.

2. Import specific items

If you only need one specific tool, you can import just that.

from random import randint

number = randint(1, 10) # Generates a random number between 1 and 10
print(number)

Here, you don't need to use random. prefix.

3. Import with an alias (nickname)

You can give a module a shorter name to make it easier to type.

import datetime as dt

current_time = dt.datetime.now()
print(current_time)

Common Standard Libraries

Here are some super useful modules that come with Python:

The math Module

Provides mathematical functions.

  • math.sqrt(x): Returns the square root of x.
  • math.ceil(x): Rounds x up to the nearest integer.
  • math.floor(x): Rounds x down to the nearest integer.
  • math.pi: The constant value of PI (3.14159...).
import math

print(math.ceil(4.2))   # Output: 5
print(math.floor(4.9))  # Output: 4

The random Module

Great for games and simulations where you need chance.

  • random.randint(a, b): Returns a random integer between a and b (inclusive).
  • random.choice(list): Picks a random element from a list.
  • random.random(): Returns a random float between 0.0 and 1.0.
import random

colors = ["red", "blue", "green"]
print(random.choice(colors))  # Output: (could be any of the three)

Creating Your Own Modules

You aren't limited to just Python's built-in modules. You can create your own! This is super useful for organizing your code, especially in larger projects.

Any Python file ending in .py can be a module.

How to do it:

  1. Create a file with functions you want to reuse (e.g., my_tools.py).
  2. Import it in another file using import my_tools.
  3. Use it by calling my_tools.function_name().

Example:

File 1: greetings.py (The Module)

def say_hello(name):
    return "Hello, " + name + "!"

File 2: main.py (Your Program)

import greetings

message = greetings.say_hello("Alice")
print(message)  # Output: Hello, Alice!

Practice

1. Dice Roll

Write a program that simulates rolling a 6-sided die using the random module.

Solution 
import random

roll = random.randint(1, 6)
print("You rolled a:", roll)

2. Circle Area Calculator

Calculate the area of a circle with radius 5 using math.pi.

Solution 
import math

radius = 5
area = math.pi * (radius ** 2)
print("Area:", area)
