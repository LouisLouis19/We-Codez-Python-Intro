What is Two Pointers?

Two Pointers is a technique where we use two index variables (called "pointers") to scan through a list at the same time.

Instead of using a slow nested loop (one loop inside another), two pointers let us solve many problems in a single pass — making our code much faster.

Real-Life Analogy: Two People Walking

Imagine a long hallway. Two people start from opposite ends and walk toward each other. Together, they can check the entire hallway much faster than one person starting at one end and walking all the way to the other.

There Are Two Main Patterns

Pattern How Pointers Move Example Problems
Inward (Converging) One starts at the beginning, one at the end. They move toward each other. Two Sum (Sorted), Palindrome Check, Container with Most Water
Same Direction (Slow & Fast) Both start at the beginning but move at different speeds. Remove Duplicates, Reverse an Array

Pattern 1: Inward (Converging) Pointers

One pointer starts at the left (index 0), and one starts at the right (last index). They move toward each other and stop when they meet.

Example: Check if a String is a Palindrome

A palindrome is a word that reads the same forwards and backwards. Examples: racecar, madam, level.

The idea: use a left pointer at the first character and a right pointer at the last character. Compare them. If they match, move both inward. If they don't match — it's not a palindrome! 

# Checking "racecar"
# [r] a c e c a [r]  → r == r? YES → move inward
#  r [a] c e c [a] r → a == a? YES → move inward
#  r  a [c] e [c] a r → c == c? YES → move inward
#  r  a  c  [e]  c  a  r → only one left in the middle → Palindrome! ✓

# Checking "hello"
# [h] e l l [o] → h == o? NO → Not a Palindrome! ✗
def is_palindrome(text):
    left = 0
    right = len(text) - 1

    while left < right:
        # Compare the characters at both pointers
        if text[left] != text[right]:
            return False   # Not a palindrome — characters don't match

        # Move both pointers inward
        left += 1
        right -= 1

    return True   # All characters matched — it's a palindrome!

print(is_palindrome("racecar"))   # Output: True
print(is_palindrome("hello"))     # Output: False
print(is_palindrome("madam"))     # Output: True
print(is_palindrome("level"))     # Output: True

Example: Two Sum on a Sorted Array

If the array is sorted, we can use two pointers to find a pair that adds up to the target — without using a dictionary! 

# numbers = [1, 3, 5, 11, 12, 21], target = 15
#
# [1] 3 5 11 12 [21] → 1+21=22 → TOO BIG  → move right pointer left
#  1  3 5 11 [12] 21 → 1+12=13 → TOO SMALL → move left pointer right
#  1 [3] 5 11 [12] 21 → 3+12=15 → FOUND! ✓
def two_sum_sorted(numbers, target):
    left = 0
    right = len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum == target:
            return [left, right]          # Found the pair!
        elif current_sum < target:
            left += 1                     # Sum too small → make it bigger
        else:
            right -= 1                    # Sum too big → make it smaller

    return None

nums = [1, 3, 5, 11, 12, 21]
print(two_sum_sorted(nums, 15))    # Output: [1, 4]  (3 + 12 = 15)

Why Move That Direction?

  • If the sum is too small: we need a bigger number → move the left pointer right (because the list is sorted, moving left pointer right gives us a bigger number).
  • If the sum is too big: we need a smaller number → move the right pointer left (moving right pointer left gives us a smaller number).

Pattern 2: Same Direction (Slow & Fast)

Both pointers start at the beginning of the list but move at different speeds.

  • Slow pointer: moves only when we find something useful.
  • Fast pointer: always moves forward, scanning the whole list.

Example: Reverse an Array

To reverse a list in-place (without creating a new list), we use one pointer at the start and one at the end, swapping elements and moving them inward. 

# Reverse ["H", "E", "L", "L", "O"]
# [H] E L L [O]  → swap H and O → [O, E, L, L, H]
#  O [E] L [L] H → swap E and L → [O, L, L, E, H]
#  O  L [L] E  H → pointers meet in middle → DONE!
# Result: [O, L, L, E, H] ✓
def reverse_array(arr):
    left = 0
    right = len(arr) - 1

    while left < right:
        # Swap the elements at left and right
        arr[left], arr[right] = arr[right], arr[left]

        # Move both pointers inward
        left += 1
        right -= 1

    return arr

chars = ["H", "E", "L", "L", "O"]
print(reverse_array(chars))   # Output: ['O', 'L', 'L', 'E', 'H']

Example: Remove Duplicates from a Sorted Array

Given a sorted list with duplicates, keep only the unique elements without creating a new list. 

# Input:  [0, 0, 1, 1, 2, 2, 3]
# Output: [0, 1, 2, 3, ?, ?, ?]  (return length=4)
#
# slow = write position (where to place the next unique value)
# fast = scan position (explores every element)
#
# [0], (0), 1, 1, 2  → slow=0, fast=1: nums[slow]=nums[fast]=0 → DUPLICATE, skip
# [0],  0, (1), 1, 2  → slow=0, fast=2: nums[slow]=0 ≠ nums[fast]=1 → UNIQUE!
#   → move slow to 1, copy nums[fast] there
# 0, [1], 1, (1), 2  → slow=1, fast=3: nums[slow]=1 = nums[fast]=1 → DUPLICATE
# 0, [1], 1, 1, (2)  → slow=1, fast=4: nums[slow]=1 ≠ nums[fast]=2 → UNIQUE!
#   → move slow to 2, copy 2
# Result: [0, 1, 2, ...] → length = 3
def remove_duplicates(nums):
    if not nums:
        return 0

    slow = 0   # Points to the last known unique element

    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:   # Found a new unique element
            slow += 1                  # Move slow forward
            nums[slow] = nums[fast]    # Overwrite with the unique value

    return slow + 1   # Length of the unique portion

arr = [0, 0, 1, 1, 2, 3, 3]
length = remove_duplicates(arr)
print(arr[:length])   # Output: [0, 1, 2, 3]
print(length)         # Output: 4

Example: Container with Most Water

Given a list of heights, find the two "walls" that can hold the most water between them. The water amount = min(left_height, right_height) × distance_between_them. 

# heights = [1, 8, 6, 2, 5, 4, 8, 3, 7]
# 
# Start with widest possible container (left=0, right=8)
# [1] 8 6 2 5 4 8 3 [7] → min(1,7)=1, width=8 → area=8
# Move the SHORTER wall (left=1, since height[0]=1 < height[8]=7)
# 1 [8] 6 2 5 4 8 3 [7] → min(8,7)=7, width=7 → area=49 ← MAX!
def max_water(heights):
    left = 0
    right = len(heights) - 1
    max_area = 0

    while left < right:
        width = right - left
        h = min(heights[left], heights[right])
        area = width * h

        max_area = max(max_area, area)   # Update max if this is bigger

        # Move the pointer with the SHORTER wall
        # (Moving the taller wall can never increase area)
        if heights[left] < heights[right]:
            left += 1
        else:
            right -= 1

    return max_area

heights = [1, 8, 6, 2, 5, 4, 8, 3, 7]
print(max_water(heights))   # Output: 49

When Should I Use Two Pointers?

Look for these clues in a problem:

  • The list is sorted and you need to find a pair or compare elements.
  • You want to avoid a nested loop (O(n²) is too slow).
  • You need to process elements from both ends at the same time.
  • The problem involves reversing, palindrome checking, or removing duplicates from a sorted array.

Practice Questions

1. Palindrome Check

Is "abcba" a palindrome? Trace the two-pointer steps to verify.

Solution 
# left=0, right=4: 'a' vs 'a' → match → move inward
# left=1, right=3: 'b' vs 'b' → match → move inward
# left=2, right=2: pointers meet → DONE
# Result: True — "abcba" IS a palindrome!

print(is_palindrome("abcba"))    # True
print(is_palindrome("python"))   # False

2. Two Sum on Sorted Array

Find two indices in [2, 3, 5, 8, 12] that add up to 10. Trace each step.

Solution 
# left=0, right=4: 2+12=14 → TOO BIG  → right=3
# left=0, right=3: 2+8=10  → FOUND! → return [0, 3]
# 2 + 8 = 10 ✓

print(two_sum_sorted([2, 3, 5, 8, 12], 10))   # Output: [0, 3]

3. Reverse a String

Reverse the list ["P", "Y", "T", "H", "O", "N"] using two pointers. Trace each swap.

Solution 
# left=0, right=5: swap P and N → [N, Y, T, H, O, P]
# left=1, right=4: swap Y and O → [N, O, T, H, Y, P]
# left=2, right=3: swap T and H → [N, O, H, T, Y, P]
# left=3 >= right=2: DONE

chars = ["P", "Y", "T", "H", "O", "N"]
print(reverse_array(chars))   # Output: ['N', 'O', 'H', 'T', 'Y', 'P']

4. Remove Duplicates

What is the unique portion length after running remove_duplicates on [1, 1, 1, 2, 3, 3, 4]?

Solution 
# Unique elements: 1, 2, 3, 4 → length = 4

arr = [1, 1, 1, 2, 3, 3, 4]
length = remove_duplicates(arr)
print(arr[:length])   # Output: [1, 2, 3, 4]
print(length)         # Output: 4

5. Slow and Fast vs Inward

Explain the difference between the "Inward (Converging)" pattern and the "Slow and Fast" pointer pattern. Give one example of each.

Solution 
# INWARD (Converging): Both pointers start at opposite ends and move TOWARD each other.
# Example: Palindrome check — left starts at index 0, right at the last index.
# They move inward until they meet in the middle.

# SLOW & FAST (Same Direction): Both start from the same end but at different speeds.
# Example: Remove Duplicates — "fast" scans every element, "slow" only advances
# when a new unique element is found. They always move from left to right.

Time Complexity

The Two Pointers technique is specifically designed to replace slow nested loops with a single efficient pass. Here's how the complexities compare:

Problem Naive Approach Two Pointers
Two Sum (sorted) O(n²) — check every pair O(n) — one pass from both ends
Palindrome Check O(n) — reverse and compare strings O(n) — single pass, no extra string created
Reverse an Array O(n) — create a new reversed list O(n) — in-place, no extra space needed
Remove Duplicates O(n) — create a new filtered list O(n) — in-place, no extra space needed

Why is Two Pointers O(n)?

Whether the pointers move inward or in the same direction, each pointer can only move across the list once. Together, they cover at most n steps total — so the algorithm is linear, or O(n). 

# Example: Palindrome check on "racecar" (n = 7 characters)
# left  starts at index 0 and moves RIGHT → at most 3 steps
# right starts at index 6 and moves LEFT  → at most 3 steps
# Together: 3 + 3 = 6 steps total → O(n)

# Compare to checking every pair of characters: O(n²)
# Two Pointers avoids redundant comparisons entirely!

Space Complexity

All Two Pointer patterns shown here work in-place — they modify the original list directly and only use a constant number of extra variables (left, right, and maybe one temp variable for swapping). That's O(1) extra space.
