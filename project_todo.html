The Big Picture: Data Structures

Unlike the previous projects which just calculated numbers on the fly, this project needs to remember things. It needs a memory storage.

Data Structure: List of Dictionaries

We need to store a list of tasks. Each task has two pieces of information: the Name ("Buy Milk") and the Status (Done or Not Done).

We represent this as a List (the container) filled with Dictionaries (the individual tasks).

todos = [ { "task": "Buy milk", "completed": False }, # Index 0 { "task": "Walk the dog", "completed": True }, # Index 1 { "task": "Do homework", "completed": False } # Index 2 ]

Part 1: The Database Manager (backend_todo.py)

This file manages our todos list. It is the only file allowed to touch the data.

1. The Global Variable

Line 3:

todos = []

This empty list is initialized when the program starts. It lives in the memory of the backend.

2. Creating a New Task

Lines 15-20:

def add_todo(task_name):
    new_todo = {} 
    new_todo["task"] = task_name
    new_todo["completed"] = False
    todos.append(new_todo)

1. We create a new empty dictionary: {}.
2. We set the key "task" to whatever the user typed.
3. We set the key "completed" to False (default).
4. We append (add) this dictionary to the end of our main todos list.

3. Updating data by Index

Lines 28-32:

def check_todo(index): 
    # todos[index] gives us the specific dictionary, e.g., the one at 0
    activity = todos[index] 
    activity["completed"] = True

We use the Index (position number) to find the exact task.
If index is 0, todos[0] gives us {"task": "Buy milk", "completed": False}.
We then change that specific dictionary's "completed" value to True.

Part 2: The Interface (todo_app.py)

1. Viewing the Data (The For Loop)

Lines 18-25:

if choice == '1':
    todos = backend_todo.list_todos() 
    for i, todo in enumerate(todos):
        status = "[x]" if todo["completed"] else "[ ]"
        print(f"{i}. {status} {todo['task']}")

Here we need to show the list to the user.

  • backend_todo.list_todos(): Fetches the raw data.
  • enumerate(todos): A fancy loop that gives us both the item (todo) AND its position number (i). We need i so the user can say "Delete number 2".
  • todo['task']: Accesses the name of the task from the dictionary.

2. User Actions with Indices

Lines 32-38:

index = int(input("Enter index to check: "))
if backend_todo.check_todo(index):
    # ...

The user sees a list like:
0. [ ] Buy milk
1. [x] Walk dog
If they want to complete "Buy milk", they type 0. The frontend converts this to an integer and sends it to the backend to update the database.
