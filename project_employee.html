🎯 What Are We Building?

We're building an Employee Management System — software that HR departments use to track employees! You can view all employees, filter by department, give raises, assign projects, and calculate department costs.

👔 What is HR Software?

Human Resources (HR) departments need to track:

  • Who works here? (Names, IDs)
  • What do they do? (Department, Role)
  • How much do they earn? (Salary)
  • What are they working on? (Projects)
  • How are they performing? (Performance rating)
🆕 What's New in This Project?
  • Lists Inside Dictionaries: Each employee has a list of projects!
  • Returning Tuples: Functions return multiple values (success, message)
  • Percentage Calculations: Salary raises calculated as percentages
  • List Comprehensions: Compact way to filter data
  • Filtering by Category: Get employees in a specific department

2. Adding New Employees (Lines 59-75)

Lines 59-75:

def add_employee(employees, name, department, role, salary):
    """Adds a new employee to the list."""
    new_id = 101
    if employees:
        new_id = max(e["id"] for e in employees) + 1
        
    new_employee = {
        "id": new_id,
        "name": name,
        "department": department,
        "role": role,
        "salary": float(salary),
        "projects": [],              # Empty list - no projects yet!
        "performance_rating": 0.0    # Default rating
    }
    employees.append(new_employee)
    return new_employee
Key points:
  1. new_id = 101 — Employee IDs start at 101 (not 1).
  2. "projects": [] — New employees start with an empty project list.
  3. "performance_rating": 0.0 — Default rating until reviewed.

3. Filtering by Department (Lines 77-79)

Lines 77-79:

def get_employees_by_department(employees, department):
    """Returns a list of employees in a specific department."""
    return [e for e in employees if e["department"].lower() == department.lower()]
📝 List Comprehension

This one-liner is called a list comprehension. It's a compact way to filter a list!

# List comprehension (1 line): [e for e in employees if e["department"].lower() == department.lower()] # Equivalent for loop (4 lines): result = [] for e in employees: if e["department"].lower() == department.lower(): result.append(e) return result

How to read it: "Give me each e from employees WHERE the department matches."

✅ Filter Example
get_employees_by_department(employees, "Engineering") # Returns: [ {"id": 101, "name": "Alice Smith", "department": "Engineering", ...}, {"id": 103, "name": "Charlie Brown", "department": "Engineering", ...} ]

4. Giving a Raise (Lines 81-93)

Lines 81-93:

def give_raise(employees, emp_id, percentage):
    """
    Increases an employee's salary by a percentage (e.g., 5 for 5%).
    Returns:
        tuple: (bool success, str message)
    """
    for emp in employees:
        if emp["id"] == emp_id:
            old_salary = emp["salary"]
            raise_amount = old_salary * (percentage / 100)
            emp["salary"] += raise_amount
            return True, f"Raise applied. New salary for {emp['name']}: ${emp['salary']:,.2f}"
    return False, "Employee ID not found."
Understanding percentage calculations:
  1. old_salary = emp["salary"] — Save the current salary.
  2. percentage / 100 — Convert percentage to decimal (5% → 0.05).
  3. raise_amount = old_salary * 0.05 — Calculate the raise.
  4. emp["salary"] += raise_amount — Add it to the salary.
✅ Raise Calculation Example
# Give Alice (salary $85,000) a 10% raise: old_salary = 85000 percentage = 10 raise_amount = 85000 * (10 / 100) = 85000 * 0.10 = 8500 new_salary = 85000 + 8500 = $93,500
📦 Returning a Tuple

This function returns TWO values at once using a tuple:

# Function returns two values: return True, "Raise applied. New salary..." # Caller receives both: success, msg = give_raise(employees, 101, 10) # success = True # msg = "Raise applied. New salary for Alice Smith: $93,500.00" # Or if employee not found: success, msg = give_raise(employees, 999, 10) # success = False # msg = "Employee ID not found."

5. Assigning Projects (Lines 95-101)

Lines 95-101:

def assign_project(employees, emp_id, project_name):
    """Assigns a project to an employee."""
    for emp in employees:
        if emp["id"] == emp_id:
            emp["projects"].append(project_name)
            return True, f"Assigned '{project_name}' to {emp['name']}."
    return False, "Employee ID not found."
How it works:
  1. Find the employee by ID.
  2. emp["projects"].append(project_name) — Add the new project to their list.
  3. Return success message.
✅ Assigning a Project
# Before: alice = {"name": "Alice", "projects": ["Website Redesign"]} assign_project(employees, 101, "Mobile App") # After: alice = {"name": "Alice", "projects": ["Website Redesign", "Mobile App"]}

6. Calculating Department Costs (Lines 103-107)

Lines 103-107:

def calculate_department_salary(employees, department):
    """Calculates total salary cost for a department."""
    dept_employees = get_employees_by_department(employees, department)
    total = sum(e["salary"] for e in dept_employees)
    return total, len(dept_employees)
How it works:
  1. First, filter to get only employees in that department.
  2. sum(e["salary"] for e in dept_employees) — Add up all salaries.
  3. len(dept_employees) — Count how many employees.
  4. Return BOTH the total and the count!
📊 The sum() Function

sum() adds up all values in a collection:

# Simple sum: sum([1, 2, 3, 4, 5]) # Returns 15 # Sum with generator expression: sum(e["salary"] for e in dept_employees) # If dept_employees contains: # Alice: $85,000 # Charlie: $92,000 # sum() returns: $177,000
